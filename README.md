# 열린기출 CBT

공인중개사 1차 부동산학개론 기출을 무료로 풀어보는 시범 사이트입니다.

- 라이브: https://yjs121256.github.io/open-gichul/
- 수록: 2023년 제34회–2025년 제36회, 부동산학개론 120문항
- 출처: 한국산업인력공단, 공공누리 제1유형 (2013년 자료부터)
- 이 저장소와 사이트는 한국산업인력공단·큐넷 공식 사이트가 아닙니다. 재가공 학습 자료입니다.
